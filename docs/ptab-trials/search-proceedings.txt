USPTO OPEN DATA PORTAL API

PTAB Trials API - Search Proceedings

Conduct a search of publicly available PTAB trial proceedings. Public PTAB AIA
trial materials are available from September 2012 onward. Searches use the
shared USPTO Open Data Portal syntax and require an API key.

GET https://api.uspto.gov/api/v1/patent/trials/proceedings/search

POST https://api.uspto.gov/api/v1/patent/trials/proceedings/search

GET accepts the common q, sort, offset, limit, facets, fields, filters, and
rangeFilters parameters. POST accepts the corresponding structured JSON search
body with optional pagination.

Successful responses contain:

- count
- requestIdentifier
- patentTrialProceedingDataBag
- facets, when requested

Each proceeding can contain:

- trialNumber
- trialRecordIdentifier
- lastModifiedDateTime
- trialMetaData
- patentOwnerData
- regularPetitionerData
- respondentData
- derivationPetitionerData

The available party bags depend on the trial type. Trial types include IPR,
PGR, CBM, and DER.

Representative request:

GET /api/v1/patent/trials/proceedings/search?q=trialMetaData.trialTypeCode:IPR&limit=1
